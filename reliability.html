기존 3D는 2D 재투영에 잘 맞아도 골반이 순간 이동하거나 발이 공중에 뜨는 문제가 있었습니다. 전체 813개 v1 진단에서 115개는 프레임 사이 골반 이동이 모델 다리 길이의 0.2배를 넘었고, 286개는 큰 바닥 간격이 여러 프레임에서 관측됐습니다. 이는 실측 3D 오차가 아닌 내부 진단입니다.

WHAM 초기 자세에 고정 체형·관절 길이, 시간 제약, 하나의 바닥·카메라 좌표계를 적용했습니다. 공개 후보에는 접지발 앞부분의 위치를 고정하는 추가 보정을 적용합니다. 착지 시점과 투구 단계, 바닥 관통, 순간 이동, 초기값에 따른 보폭 변화를 검사하고 원본 장면과 시각 대조합니다. 기존 RTMPose Halpe-26 최종 2D 수치는 유지합니다.

처리 현황을 불러오는 중…

보폭의 정량 정확도는 아직 검증되지 않았습니다. 카메라와 선수 키를 실측하지 않은 단안 영상입니다. 실제 신장 대신 SMPL 추정 체형을 고정했습니다. 18.44m 규격만으로는 영상 속 투구판·홈플레이트의 대응점과 카메라를 확정할 수 없어 절대 축척으로 사용하지 않았습니다. 바닥 접지와 일정한 뼈 길이는 모델에 부여한 조건이며 정확도를 입증하는 독립 측정이 아닙니다. 특정 평균 보폭으로 결과를 늘리지 않습니다. 요청에 따라 검토가 필요한 결과도 3D 미리보기와 다운로드를 제공합니다. 기존 검사 결과와 검토 사유는 유지하며 화면에 표시합니다.

선별한 사례 비교

왼쪽은 기존 v1, 오른쪽은 새 추정입니다. 동일한 화면 범위와 고정 바닥에서 0.5배속으로 재생합니다. 아래 문제 사례들은 진단용이며, 개선된 움직임만으로 실제 보폭이 복원됐다고 판단할 수 없습니다. 원본 중계 영상·음성은 포함하지 않습니다.
