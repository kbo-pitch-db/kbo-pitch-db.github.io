GVHMR + MotionBERT 팔 결합 실험 분석 · v3

튜닝 6개에서 고정한 후보: raw_ray_flip. 선수·원본 영상이 다른 6개에 같은 선택을 적용했습니다. 메인 813개 결과에는 결합 실험을 적용하지 않았습니다.

메인 GVHMR의 체형·하체 로컬 회전·카메라·골반 전역 궤적과 보폭은 고정했습니다. 상완·팔꿈치만 수정하며 손목 로컬 회전은 유지했습니다. MotionBERT의 17관절 lifting으로 관측되지 않는 실제 손목/손바닥 회전의 개선은 주장하지 않습니다.

원본 손목/팔꿈치 재투영과 이번 fitting에서 제외한 매 5번째 프레임, fitting에 넣지 않은 RTMW384의 별도 관측을 비교했습니다. 초기 추정기는 전체 프레임을 보았습니다. 모든 수치는 관측 정합성 또는 모델 진단이며 KBO 3D GT가 아닙니다. 음의 px 변화는 2D 오차 감소입니다. 후방 위치 증가는 정확도 개선 건수에 포함하지 않습니다.

선택 기준은 손을 가장 뒤로 보내는 후보가 아닙니다. 기본 3D와 함께 MotionBERT 없이 같은 팔 자유도만 2D 재적합한 대조군도 포함합니다. 선택 후보는 MotionBERT 설정들 중 골랐으며, 대조군보다 우수하다는 뜻이 아닙니다. 원본 정합·동작 보존 조건을 적용하고 튜닝의 제외 프레임 손목/팔꿈치 오차와 관측 속도 타이밍 차이로 설정을 고정했습니다. 확인 클립은 선택에 쓰지 않았으며, 이전 연구에 쓰인 자료라는 한계가 있습니다.

이번에 확인된 점

메인은 이미 813개 / 123명 모두 GVHMR 접지 fitting으로 배포했고, 여기의 팔 실험은 메인에 적용하지 않았습니다. 이 프리뷰는 관측에 맞는 새로운 깊이 후보를 만드는 연구 결과이며 실제 코킹 3D 정답을 검증한 결과가 아닙니다.

고정 설정 raw_ray_flip는 튜닝 5/6, 다른 선수·원본 영상의 최종 비교 6/6에서 원본 정합·동작 보존 기준을 만족했습니다. 최종 비교의 손목 p95 중앙값은 5.54 → 1.62 px, 이번 팔 재적합에서 직접 제외한 프레임은 4.96 → 2.82 px였습니다. 초기 모델과 메인 fitting은 전체 입력을 보았으므로 완전히 미관측한 2D 검증이나 KBO 3D GT가 아닙니다.

무엇이 기여했는가

  1. V1: MotionBERT 팔을 그대로 이식하면 원본 재투영이 크게 틀어졌고, SMPL 전신 pose corrective가 발 표면 마커까지 움직였습니다. 가장 보수적인 축 회전 후보는 원본을 덜 망가뜨렸지만 팔 변화가 매우 작아 목표한 개선으로 채택하지 않았습니다.
  2. V2: 국소 팔 마커와 시간에 연결된 보정만으로는 원본과 멀리 떨어진 초기 팔 자세를 충분히 고치지 못했습니다. 발 고정은 이 실험 범위의 정의이며 접지 정확도 개선 증거가 아닙니다.
  3. V3: 원본의 팔꿈치·손목 광선과 고정된 상완·전완 길이로 네 가지 앞뒤 깊이 해를 만들었습니다. MotionBERT는 XY 위치를 이식하지 않고 상대 깊이 선택에만 썼습니다. 추가 fitting보다 이 초기 후보의 제외 프레임 정합성이 좋아, 기본 프리뷰는 추가 fitting 전 후보입니다. 모든 다른 해도 비교할 수 있습니다.

픽셀 오차 감소의 대부분은 원본 조건부 기하에서 왔습니다. MotionBERT 없이 기존 GV 깊이를 고르는 대조군도 최종 비교 손목 p95 1.18 px를 얻었습니다. MotionBERT가 바꾸는 것은 주로 팔의 앞뒤 해석이며 그 깊이가 정답이라는 증거는 아직 없습니다. 같은 2D를 설명하는 다른 깊이 후보를 평균하지 않았습니다.

확인하지 못한 것

별도 RTMW 관측에 대한 손목 p95 중앙값은 58.38 → 58.19 px로 거의 그대로이며 추가 정확도 증거가 강하지 않습니다. 이 모델의 native 점수는 실제로 1.02–7.06 범위인 decoder 값이어서 확률이 아닙니다. 기존 동결 기준은 유지하고 점수 순위별 민감도를 사후 진단으로만 별도 저장했습니다. RGB blur·가림에서 검출기들이 크게 다릅니다. 원본 대조와 source detector 정합을 실제 3D 각도·거리 정확도로 바꾸어 해석하지 않습니다.

발과 하체 보존은 의도한 실험 범위입니다. 카메라·지면·축척은 기존 단안 추정에 조건부이며, 손목/손바닥 로컬 회전은 바꾸지 않았습니다. 17관절 MotionBERT로 실제 손목 굽힘을 관측했다고 주장하지 않습니다. 사람의 수동 검수 완료나 실제 MPJPE를 부여하지 않았습니다. 다음 우선순위는 같은 투구의 확인된 리플레이, 원본 RGB의 팔–몸통 가림 순서처럼 네 깊이 후보를 구별하는 추가 관측입니다. 단순히 손을 더 뒤로 보내는 설정이나 재투영만 낮추는 설정을 메인으로 채택하지 않습니다.
