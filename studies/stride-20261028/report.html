보폭 중심 선택: GVHMR f4 기본 · NLF 비교 유지

비교기 열기 · 전체 아카이브

기존 모션에서 주로 문제가 된 짧은 보폭을 기준으로 독립 초기 추정과 fitting을 분리했다. 원본에 더 부합한다는 검토 의견과 초기값 보존 결과를 반영해 GVHMR f4를 기본 후보로 골랐다. NLF도 합리적인 대안으로 남겼다. 이 선택은 사후 연구 판단이며 새로운 블라인드 3D 정확도 검증을 뜻하지 않는다.

초기값부터 달랐던 발 벌어짐

같은 20개 클립, 같은 2D 기반 착지 구간에서 native 발목 사이 전체 3D 거리의 구간 최소·최대 중간값을 구하고 클립 중앙값을 집계했다. 단위는 모델 다리 길이다. 실제 투구판–착지 보폭과 구분한다.

GVHMR의 발 벌어짐은 초기 추정에 이미 존재하고 fitting 뒤에도 대부분 유지됐다. 평균 보폭에 맞춘 강제 확대는 하지 않았다. WHAM 계열 초기값이 짧은 사례에서는 접지 고정만 푸는 것으로 충분하지 않았다. 큰 거리 자체를 정답으로 선택하는 규칙은 사용하지 않는다.

NLF도 같은 클립에서 비교

유지한 구분

① 동일 프레임 발목 간격 ② 착지 구간의 간격 범위 ③ 레그리프트 부근 뒷발 발목 가설에서 앞발까지의 3D 변위 ④ 추정 투구 축 방향 가설별 변위 범위를 따로 저장했다. 초기 뒷발 지지 가설이 없거나 좌우투와 이벤트가 충돌하면 해당 값을 unknown으로 둔다. 공 관측 없이 릴리스를 확정하지 않는다.

기존 813개 결과와 최종 Halpe-26은 보존하고 36개 실험 표본을 별도 제공한다. 처리하지 않은 12개 튜닝 클립도 고정 48개 목록에 그대로 남겼다. 판정만 바꾼 복구는 0이며 사람 수동 검수 완료로 승격하지 않았다. 실제 KBO 3D GT, 절대 보폭, 전역 이동·접지 정확도는 미확정이다.
