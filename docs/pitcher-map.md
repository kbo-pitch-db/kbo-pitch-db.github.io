# 투수 유사도 지도

[Visuals → 투수 유사도 지도](https://kbo-pitch-db.github.io/#visuals/map)에서 선택한 연도의 비교 대상 투수를 모두 표시합니다. 기존 [비슷한 투수 찾기](visuals-affinity.md)와 같은 구종 구성·구사 비율·구속·HB·IVB 분포를 사용합니다. 새 점수나 선수 평가 등급을 만들지 않습니다.

## 포함 범위

| 연도 | 지도에 표시하는 투수 | 기록 범위 |
|---|---:|---|
| 2024 | 154명 | 2024-03-23–2024-10-01 |
| 2025 | 146명 | 2025-03-22–2025-10-04 |
| 2026 | 125명 | 2026-03-28–2026-08-04 |

유효 투구가 500구 이상이고 확보한 본인 기록의 90% 이상을 비교에 쓸 수 있는 투수가 대상입니다. 홈페이지에 등록된 투수 전원을 뜻하지 않습니다. 2026년 8월 5일 이후 기록은 아직 포함하지 않았습니다. 연도 사이의 기록을 합치지 않습니다.

## 배치와 해석

모든 투수 쌍의 기존 유사도를 계산한 뒤 `d = 1 - 유사도/100`을 거리로 사용합니다. [metric MDS의 SMACOF 방법](https://scikit-learn.org/stable/modules/manifold.html#multidimensional-scaling)으로 원래 거리와 평면 거리의 제곱 오차 합을 줄입니다. NumPy로 계산하며, 고전 MDS 초기화 1개와 고정 난수 시드의 초기화 4개 중 오차가 가장 작은 배치를 저장합니다. 좌표의 회전과 부호를 고정해 다시 생성할 수 있게 했습니다.

두 축에는 구속이나 무브먼트처럼 직접 측정한 단위가 없습니다. 지도의 오른쪽이나 위쪽을 선수의 능력으로 해석할 수 없습니다. 모든 거리 관계를 2차원에서 재현할 수 없으므로, 눈으로 가장 가까워 보이는 투수가 실제 유사도 1위라는 보장도 없습니다. 연도별 배치는 독립적이어서 해마다 좌표가 이동한 정도를 선수 변화량으로 해석하지 않습니다.

실제 배치에서 확인한 오차를 `pitcher-map.json`의 `audit`에 남겼습니다. `normalizedStress`는 거리의 제곱 오차 합을 원래 거리의 제곱 합으로 나눈 뒤 제곱근을 구한 값입니다. `nearest10Recall`은 원래 유사도 상위 10명과 평면에서 가까운 10명이 얼마나 겹치는지 투수별로 계산한 평균입니다.

| 연도 | normalizedStress | nearest10Recall |
|---|---:|---:|
| 2024 | 0.2926 | 42.6% |
| 2025 | 0.2952 | 43.6% |
| 2026 | 0.2960 | 51.0% |

전체 지도에서는 각 투수와 실제 유사도가 높은 두 명을 연결합니다. 양쪽에서 선택한 같은 연결은 한 번만 그립니다. 선수를 선택하거나 마우스를 올리면 해당 투수와 비슷한 5명의 연결선을 굵게 표시하고, 기존 계산의 점수를 소수점 한 자리로 표시합니다. 지도상의 근접 순위로 연결이나 목록을 만들지 않습니다. 각 목록의 ‘비교’ 링크는 같은 연도·두 선수로 기존 구종별 분포 화면을 엽니다.

## 조작과 공유

- 원의 색 비율은 실제 비교 표본의 구종 비율입니다. 선수를 검색해도 점을 삭제하거나 배치를 다시 계산하지 않습니다.
- 클릭·터치·이름 검색으로 선택합니다. 동명이인은 선수 코드를 함께 표시합니다.
- 마우스를 올리면 원이 커지고 이름·투구 수·주요 구종과 유사도 카드가 나타납니다. 해당 투수와 비슷한 5명은 선명하게 남고 다른 점들은 흐려집니다. 미리보기를 끝내면 클릭으로 선택해 둔 투수의 연결로 돌아갑니다. 마우스를 올리는 것만으로 선택이나 공유 주소가 바뀌지 않습니다.
- 오른쪽 유사도 목록에 마우스를 올리면 선택한 투수와 그 선수의 연결을 강조합니다. 키보드로 초점을 옮겨도 같은 정보를 볼 수 있고, Escape로 미리보기를 닫습니다. 움직임 줄이기 설정에서는 확대·툴팁의 전환 애니메이션을 끕니다.
- 확대·축소·전체 보기 버튼, 드래그, 터치 핀치와 Ctrl/Command+휠로 지도를 조작합니다. 일반 휠은 페이지를 스크롤합니다.
- 키보드 방향키로 점 사이를 이동하고 Enter 또는 Space로 선택합니다. `+`, `-`, `Home`으로 확대·축소·전체 보기를 조작합니다.
- 작은 화면에서는 지도 다음에 선택한 선수와 실제 유사도 목록을 표시합니다.

```
/#visuals/map?year=2026
/#visuals/map?year=2024&player=65320
```

공유 링크에는 연도와 선택한 선수만 저장합니다. 기존 개별 유사도 링크, 선수 화면과 데이터 탐색 링크는 유지합니다.

## 파일과 재생성

```sh
OPENBLAS_NUM_THREADS=1 python scripts/build_pitcher_map.py
```

연도별 `affinity-YYYY.json.gz`를 읽고 [pitcher-map.json](../data/visuals/pitcher-map.json)에 고정 좌표와 상위 2명 연결을 저장합니다. 생성할 때 원본 압축 파일의 SHA256을 확인합니다. 화면은 지도에 기록한 소스 해시와 투수 ID 전체가 연도별 유사도 목록과 일치하는지 확인합니다. 연도별 기록 생성기와 기본 유사도 생성기도 마지막에 이 지도를 갱신합니다. 동작 영상과 투구 기록은 수정하지 않습니다.

`tests/test_pitcher_map.py`는 모든 선수의 포함 여부, 연도와 소스 해시, 실제 상위 2명 연결과 점수, 유사도 계산, 실제 배치 오차를 확인합니다. `tests/pitcher_map_browser_qa.py`는 기존 화면과의 점수 일치, 선택·검색·연도·공유·이력·비교 링크·키보드·확대·드래그·터치 및 모바일 배치를 확인합니다. `tests/pitcher_map_hover_browser_qa.py`는 마우스와 키보드 미리보기, 선택·주소·좌표 유지, 연결선의 정확한 점수, 터치와 움직임 줄이기 설정을 확인합니다.
