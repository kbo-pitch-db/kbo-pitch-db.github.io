# Player similarity · 2024 KBO

`/#visuals`에서 시각화 목록을, `/#visuals/affinity`에서 선수 비교를 볼 수 있습니다.

이 기능은 Baseball Savant의 [Affinity](https://baseballsavant.mlb.com/affinity-pitchersAndHitters-byHittingProfile)에서 아이디어를 가져온 KBO 버전입니다. 사용자의 요청에 따라 **투구 결과 비율**로 비교합니다. Savant의 타구 속도·발사각에 따른 타구 유형 비교나 원본의 유사도 모델을 재현한 기능은 아닙니다.

## 자료 범위

- 출처: [공개된 2024년 네이버 PTS 기록](https://github.com/leekichang/where-do-the-robot-umpires-see/blob/37cf62be0604aa8a7f077759eebf7a6eda002edb/data/2024.csv).
- 2024-03-23부터 2024-10-01까지 708경기, 확보한 215,525구입니다. KBO 시즌 전체 투구를 빠짐없이 수집한 기록은 아닙니다.
- 번트 파울 662구와 번트 헛스윙 131구를 제외한 214,732구로 비율을 계산합니다.
- 비교 대상은 번트를 제외하고 **500구 이상** 있는 선수입니다. 타자 135명의 139개 타석 방향별 기록, 투수 154명이 포함됩니다. 서로 다른 타석 방향은 별도 기록으로 다룹니다.
- 선수별 표본 수·경기 수·기간을 집계합니다. 개별 선수는 전체 자료의 기간보다 짧은 기간만 관측되었을 수 있습니다.
- 이 비교 자료는 홈페이지의 투구 동작 영상 및 데이터 탐색에 있는 경기 기록과 별도의 집계입니다. 동작 영상을 새로 추정하거나 기존 기록과 연결하지 않습니다.

원본 CSV의 `Hit`는 **인플레이**입니다. 안타와 아웃을 구분하는 값이 아니므로 타율이나 안타 확률로 해석하지 않습니다. `Strike`는 루킹, `Swing`은 헛스윙입니다. `Ball`은 볼 한 개이며 볼넷이 아닙니다. 삼진·볼넷·홈런이나 타석 결과는 이 CSV에서 추정하지 않습니다.

## 계산

선수별로 볼·루킹·헛스윙·파울·인플레이의 관측 횟수를 셉니다. 다섯 횟수의 합이 분모이며, 별도의 보간이나 가상 표본을 넣지 않습니다. 타자는 실제 타석 방향별 상대 투구, 투수는 양쪽 타석 방향을 합한 본인의 투구를 사용합니다. 타자끼리, 투수끼리만 비교합니다.

각 선수의 비율 벡터를 p, q, 그 평균을 m이라 하면 다음과 같이 계산합니다.

```
m = (p + q) / 2
JS(p, q) = 0.5 × Σ pᵢ log₂(pᵢ / mᵢ) + 0.5 × Σ qᵢ log₂(qᵢ / mᵢ)
유사도 = 100 × (1 − √JS(p, q))
```

비율이 0인 항의 기여도는 0입니다. 같은 비율은 100, 공통된 결과가 전혀 없는 비율은 0입니다. 화면에는 소수점 한 자리로 표시하지만 정렬과 기준 필터에는 반올림 전 값을 사용합니다. 분포가 비슷한 선수들이 많으면 점수가 전반적으로 높을 수 있습니다. 점수는 백분위나 확률, 실력 평가가 아닙니다.

지도는 기준 선수와 유사 선수의 연결을 보여줍니다. 각 원의 색 비율은 해당 선수의 결과 비율입니다. **원의 위치와 원 사이의 거리는 유사도 좌표가 아닙니다.** 유사도는 숫자로 표시하며, 별도의 2D 임베딩은 사용하지 않습니다. 지도에는 화면 크기에 따라 가까운 12명 또는 6명을 표시합니다. 옆 목록에는 기준을 통과한 선수를 모두 제공합니다. 아래 점 분포는 비교 가능한 모든 선수의 점수를 0–100 고정 축에 표시합니다.

비교 막대는 두 선수에게 같은 0–100% 축을 사용합니다. 실선 막대와 사선 무늬 막대, 선수 이름, 숫자를 함께 표시해 색에만 의존하지 않습니다.

동일한 투구 결과 비율만으로 구종·코스·상대 선수·카운트의 차이나 타구의 질을 알 수는 없습니다. 표본 수를 함께 보고 탐색을 위한 비교로 사용하세요.

## 공유 링크

```
/#visuals/affinity?players=hitters&player=68050-L&s=95&compare=79530-R
```

`players`는 `hitters` 또는 `pitchers`, `player`는 기준 선수의 키, `s`는 최소 유사도(0–100), `compare`는 비교 선수의 키입니다. 타자의 키에는 실제 타석 방향이 붙습니다. 유효하지 않은 선수나 비교 대상은 같은 집단 내 유효한 선수로 바꿉니다. 이 매개변수는 URL의 해시 안에만 저장하며 기존 선수·고급 분석 링크의 매개변수와 구분합니다.
