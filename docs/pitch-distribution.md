# 시즌별 구속 분포

[Visuals → 시즌별 구속 분포](https://kbo-pitch-db.github.io/#visuals/distribution)는 투수의 구종별 구속 분포를 시즌 순서대로 재생합니다. [Baseball Savant의 Pitching Distributions](https://baseballsavant.mlb.com/visuals/statcast-pitch-distribution?playerId=547943)의 구종별 곡선, 전체 투구 곡선, 이전 시즌 잔상과 재생 동작을 참고했습니다. KBO 기록을 사용하며 구속 단위는 km/h입니다.

## 자료와 분모

기존 [2024–2026년 연도별 기록](season-records.md)을 그대로 읽습니다. 전체 449명 가운데 선택한 투수의 기록만 불러오며, 유사도 화면의 500구 이상 조건은 사용하지 않습니다. 2026년 원본은 8월 4일까지이며 투수별 마지막 기록 날짜는 다를 수 있습니다. 동작 영상과 메커니즘은 변경하지 않았습니다.

- 유한하고 0보다 크며 250km/h 미만인 원본 구속만 사용합니다. 구속이 없는 기록은 채우지 않습니다.
- 구속은 1km/h 구간으로 집계합니다. 예를 들어 140.0과 140.9km/h는 `[140,141)` 구간에 들어갑니다.
- 각 구종의 높이는 **구종 내 비율이 아니라, 해당 시즌의 유효한 전체 구속 기록에서 차지하는 비율**입니다. 따라서 구종별 비율을 더하면 전체 투구 곡선과 일치합니다.
- 구종을 확인할 수 없는 유효 구속은 ‘미분류’에 포함하며 전체 투구에서도 빠뜨리지 않습니다. 다른 구종으로 추측해 넣지 않습니다.
- 슬라이더에는 구속 기록이 실제로 있는 시즌만 표시합니다. 한 시즌만 있으면 그 분포는 표시하되 재생·이전·다음·슬라이더는 비활성화합니다.

기본 선수는 원본 링크와 같은 류현진입니다. 기존 공개 자료에서 2024년 2,490구, 2025년 2,267구, 2026년 1,529구를 사용합니다. 기록 범위와 분모는 화면에 표시하며 완전한 시즌으로 표현하지 않습니다.

## 곡선과 시즌 전환

곡선은 실제 1km/h 구간 빈도에 양수 가중치의 3차 B-spline을 사용해 부드럽게 표시합니다. 양 끝에 0인 구간을 추가하므로 음수 빈도를 만들지 않고 각 구종의 구사 비율에 해당하는 면적을 보존합니다. 툴팁에는 부드럽게 그린 높이가 아니라 원본 구간의 실제 투구 수와 전체 대비 비율을 표시합니다.

같은 투수의 모든 확보 시즌을 기준으로 x축과 y축 범위를 한 번 정합니다. 시즌을 넘겨도 축이 바뀌지 않습니다. 구종 색상도 기존 선수 페이지·유사도 화면과 같습니다. 해당 시즌에 없는 구종은 곡선이 0이며 범례에는 ‘—’로 표시합니다.

시즌을 바꿀 때 곡선 높이를 650ms 동안 보간합니다. 이는 화면 전환이며 새 관측값이나 중간 시즌을 생성하는 것이 아닙니다. 전환 중에는 툴팁을 숨기고 그래프를 `aria-busy`로 표시합니다. 전환이 끝나면 실제 선택 시즌의 빈도와 정확히 일치합니다. 이전 시즌 겹쳐보기는 선택한 시즌보다 앞선 실제 기록만 표시합니다.

## 조작과 링크

- 연도를 지정하지 않고 처음 열면 첫 시즌부터 한 번 자동 재생하고 마지막 시즌에서 멈춥니다. ‘다시 재생’으로 처음부터 볼 수 있습니다.
- 슬라이더, 연도 버튼, 이전·다음 버튼을 조작하면 자동 재생이 멈춥니다. 빠르게 슬라이더를 움직여도 현재 표시 중인 곡선에서 새 목표로 전환합니다.
- 구종 범례를 마우스로 가리키거나 키보드로 선택하면 해당 곡선을 강조합니다. 클릭하면 강조를 유지하고 다시 클릭하면 해제합니다.
- 선수 검색은 이름과 선수 코드를 지원합니다. 동명이인에는 코드를 함께 표시합니다.
- 다른 화면으로 나가거나 브라우저 탭을 숨기면 타이머와 곡선 전환을 중단합니다.
- ‘움직임 줄이기’ 설정에서는 자동 재생을 시작하지 않고, 시즌 전환 시 보간 애니메이션을 끕니다. 사용자가 명시적으로 재생하면 실제 시즌을 차례로 표시합니다.

```
/#visuals/distribution
/#visuals/distribution?player=76715&year=2025
/#visuals/distribution?player=76715&year=2026&pitch=4-Seam&trail=0
```

선수·시즌·강조 구종·이전 시즌 표시 여부를 공유할 수 있습니다. 자동 재생 중에는 브라우저 이력 항목을 계속 추가하지 않습니다. 연도가 포함된 링크는 그 시즌에서 멈춘 상태로 엽니다.

## 구현과 확인

`pitch_distribution_core.js`가 빈도·분모와 곡선을 계산하고, `pitch_distribution.js`와 `pitch_distribution.css`가 검색·재생·슬라이더·공유·툴팁을 담당합니다. 기존 `SeasonRecords`의 선수별 압축 묶음을 재사용하므로 새 데이터 사본이나 외부 차트 라이브러리는 필요하지 않습니다.

`tests/pitch_distribution_core.test.cjs`는 실제 구간 경계와 분모, 누락·미분류·없는 시즌, 곡선의 면적, 보간의 끝점, 기존 류현진 3개 시즌 기록을 확인합니다. `tests/pitch_distribution_browser_qa.py`는 자동 재생·반복·일시정지·슬라이더·축 고정·잔상·구종 강조·원본 구간 툴팁·검색·단일 시즌·공유·이력·재시도·키보드·모바일·움직임 줄이기를 실제 브라우저에서 확인합니다.
